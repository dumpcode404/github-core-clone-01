Standalone GitHub-compatible git forge: one Node 22 process serving git smart HTTP (upload-pack v2, receive-pack v0), REST v3, GraphQL v4, and MCP from its own in-memory store — no UI, no outside service, no git binary.

## Run it

```sh
node main.ts
```

It binds an ephemeral port, registers with the suite, serves until the suite reports done, then exits. See RULES in the competition kit for the wire contract.
